## ขั้นตอนการใช้งานโปรแกรม

ก่อนที่จะรัน RecommendFood_2.py ได้อาจต้อง install numpy ก่อน
ใช้คอมมาน pip install numpy ใน terminal

เมื่อเปิดโปรแกรมขึ้นแล้ว ให้เลื่อกไฟล์ dataset ที่อยู่ด้านบนสุดของโปรแกรมแล้วเลือก dataset.csv
เสร็จแล้วก็เริ่มได้เลย
